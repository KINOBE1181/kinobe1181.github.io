Selected Projects

Smart Course Search — AI Engineering

As part of my AI engineering studies, I developed a Python-based semantic search application using Ollama and Pinecone.

The application uses the nomic-embed-text model to generate vector embeddings from course titles, sections, and descriptions. These embeddings are stored in a Pinecone vector database, allowing users to search for relevant course information based on meaning rather than exact keywords.

I implemented section-level searching and similarity-based ranking, allowing the application to return relevant course sections with their descriptions and similarity scores.

I tested the application with sample course data and successfully retrieved ranked results. I also improved the program so it reuses an existing Pinecone index instead of deleting and recreating it every time the program runs.

This project helped me better understand vector databases, embedding models, semantic search, and how AI applications retrieve relevant information.

Technologies: Python, Ollama, Pinecone, LangChain, Vector Embeddings

Database Transactions and Concurrency Control

In my Transactional Cyber Systems coursework, I explored how databases handle multiple transactions while maintaining data consistency.

One assignment, "One Doctor Stays," involved using SQLite to enforce a scheduling rule requiring at least one doctor to remain on call. I tested concurrent transactions using two terminals and examined how database locking affected the order of operations.

I used BEGIN IMMEDIATE, conditional UPDATE statements, and transaction commits to prevent both doctors from going off call. I also observed how a transaction waiting for a lock reads the updated database state after another transaction commits.

This assignment helped me understand transaction isolation, database locking, and how careful transaction design prevents inconsistent data.

Technologies: SQLite, SQL, Linux, Transaction Management

Parallel Programming and MPI Communication

Through my Parallel and Concurrent Systems coursework, I studied how multiple processes execute and communicate in parallel programs.

One MPI exercise focused on a C program where non-main processes send short messages to the main process. The main process identifies the rank of the process that sent a particular message.

The exercise introduced process ranks, message passing, and communication between independently executing processes.

It also helped me understand how parallel programs coordinate information and why communication between processes is important.

Technologies: C, MPI, Linux, Parallel Programming
